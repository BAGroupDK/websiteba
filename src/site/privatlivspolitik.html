Ingen cookies og ingen sporing

Hjemmesiden sætter ingen cookies og bruger ingen analyseværktøjer, annoncenetværk, sociale medie-knapper eller andre tjenester fra tredjeparter. Skrifttyper og billeder hentes fra vores egen hjemmeside – ikke fra fx Google. Derfor beder vi dig heller ikke om samtykke til cookies.

Hosting hos GitHub

Hjemmesiden hostes på GitHub Pages, som leveres af GitHub, Inc. (USA). Når du besøger siden, modtager GitHub – som ved ethvert besøg på en hjemmeside – teknisk nødvendige oplysninger som din IP-adresse, tidspunkt og hvilken side der blev hentet. GitHub bruger oplysningerne til at levere siden og beskytte tjenesten mod misbrug. Vi har ikke selv adgang til disse oplysninger.

Behandlingen sker på grundlag af vores legitime interesse i at kunne vise hjemmesiden sikkert (databeskyttelsesforordningens artikel 6, stk. 1, litra f). Overførsel til USA sker efter GitHubs vilkår, herunder EU-U.S. Data Privacy Framework. Læs mere iGitHubs privatlivserklæring.

Når du skriver eller ringer til os

Kontaktformularen på hjemmesiden åbner blot dit eget mailprogram – hjemmesiden sender eller gemmer ikke selv noget. Hvis du sender os en e-mail eller ringer, bruger vi de oplysninger, du giver os, til at besvare din henvendelse, og vi gemmer dem ikke længere end nødvendigt.
